## 🧭 How to Use Skillbolt

Skillbolt’s interface focuses on clarity and ease. Here’s a quick guide to get started:

### 1. Explore Skills

- Click the “Browse Skills” tab.
- You’ll see a list of available AI skills ready to add.
- Scroll through or use the search box to find specific skills.

### 2. Add Skills

- Select any skill you want.
- Click the “Add” button.
- Skillbolt will install the skill and make it available for your AI agents.

### 3. Manage Existing Skills

- Go to “My Skills” to see what you have installed.
- From here, you can activate, deactivate, or remove skills.

### 4. Share Skills

- Create new skills by clicking “New Skill” and follow prompts.
- Share your skills with others by exporting and sending skill packages.
